# Личный сейф (Personal Safe)

Нативное Android-приложение (Kotlin + Jetpack Compose) для хранения токенов, паролей,
карт, документов и других секретов. Секреты шифруются ключом устройства (Android Keystore),
ИИ-агент распознаёт находки из буфера обмена и раскладывает их по категориям.

## Возможности

- **Два режима** — «локальный сейф» (данные только на телефоне) и «вход через Google»
  (Credential Manager: вход и резервная копия в вашем аккаунте). Client ID вшит в сборку,
  поэтому вход работает сразу, без настройки. Переключение режима — в «Настройках» →
  «Сменить аккаунт или режим». Плюс разблокировка по биометрии.
- **ИИ-агент** — любой OpenAI-совместимый API. По умолчанию подставлена **бесплатная модель
  Groq** (ключ без карты, 1000 запросов в сутки, распознавание изображений); если лимит на сутки
  закончится, агент скажет, когда он обновится. Настраиваются провайдер, base URL, API-ключ,
  модель и модель для изображений, температура, проверка связи и загрузка списка моделей.
- **Анализ находки** — поле ввода, кнопка «Из буфера», выбор файла, ссылка на изображение.
  При входе на экран буфер обмена считывается автоматически.
- **Определение типа и категории** — агент определяет тип (токен, пароль, API-ключ, ID-карта,
  банковская карта, паспорт, аккаунт, Wi-Fi, PIN и др.) и либо кладёт в существующую категорию,
  либо предлагает создать новую (например, «Яндекс»).
- **Банк по номеру карты** — по первым цифрам (BIN) определяется предполагаемый банк-эмитент
  (Сбербанк, Т-Банк, Альфа-Банк, ВТБ, Газпромбанк) и подсказываются ссылки на управление картами.
- **Иконки категорий** — сначала ищутся логотипы брендов в интернете (Clearbit → Google favicon →
  DuckDuckGo), при неудаче генерируется «стеклянная» иконка с инициалами.
- **Поиск по изображению** — выберите картинку (скриншот карты, логотип, страницу настроек):
  агент определит бренд и тип, покажет совпадения в сейфе, а также галерею всех секретов
  со ссылками на изображения.
- **Группировка по бренду** — переключатель «Категории / Бренды» в сейфе собирает все секреты
  одного бренда в одну карточку (логотип, число секретов), независимо от категорий.
- **Подробное описание** — раскрывающийся блок с информацией, найденной агентом: кому принадлежит
  токен, для чего используется, ссылки на страницы управления/перевыпуска.
- **Редактирование** — карточки категорий (название, тип, описание, домен, цвет, иконка) и карточки
  секретов (значение, описание, примечание, избранное).
- **Несколько секретов в одной записи** — в записи можно добавить любое число дополнительных полей
  («Логин», «Код восстановления» и т.п.) кнопкой «Добавить значение», удалить поле корзиной, а глаз
  открывает значение и делает его доступным для копирования.
- **Оформление** — 8 наборов тем, светлый/тёмный/системный режим, динамические цвета Android 12+,
  стеклянные эффекты.
- **Заставка** — 5-секундная анимация со стеклянным щитом, сиянием, частицами и прогрессом.

## Что нового в 2.7

- **Google-вход работает сразу, без настройки.** Client ID вшит в сборку (это публичный
  идентификатор, не секрет) — новый пользователь просто нажимает «Войти через Google».

## Что нового в 2.6

- **Два режима: локальный и через Google.** На стартовом экране теперь две равноправные кнопки:

- **Главный экран компактнее.** Счётчик записей в карточке категории перенесён вправо от пиктограммы,

- **Несколько значений в одной записи.** В записи доступны дополнительные скрытые поля: кнопка «+»

- **Свёрнутые второстепенные настройки.** «Набор тем», «Прозрачность элементов» и «Провайдер и модель»
  по умолчанию свёрнуты и раскрываются по нажатию.
- **Бесплатная модель по умолчанию.** ИИ-агент настроен на бесплатную модель Groq (`qwen/qwen3.8-27b`):
  ключ выдаётся без карты, лимит 1000 запросов в сутки, есть распознавание изображений. Когда лимит
  исчерпан, показывается понятное сообщение о том, когда он обновится (по заголовкам провайдера, если
  они есть). В настройках есть кнопка «Получить бесплатный ключ» и пресеты OpenRouter, Google Gemini,
  aitunnel и OpenAI.
- **Логотип бренда — на прозрачном фоне.** Логотипы брендов теперь показываются целиком, без обрезки
  и без подложки-квадрата: виден только сам логотип.
- **Обновлён значок приложения.** Более сочный замок с переливами: градиентный корпус, блик по кромке,
  объём и контур.

## Что нового в 2.5

- **Копия сохраняется сама, без фразы.** Через несколько секунд после каждого изменения сейф
  уходит в Google Drive. Фразу вводить больше не нужно.
- Ключ шифрования лежит рядом с копией — отдельным файлом в той же скрытой папке приложения.
  Поэтому копию можно восстановить на любом устройстве, где выполнен вход в тот же Google-аккаунт.
  Плата за удобство: копию защищает доступ к вашему Google-аккаунту (включите двухэтапную
  аутентификацию), а не отдельный секрет.
- **Защита от затирания.** Если в Drive лежит копия, где секретов больше, чем на этом устройстве
  (например, приложение только что установлено на новый телефон), автоматическая копия
  останавливается и предлагает сначала восстановиться. Пустой сейф копию не затрёт.
- Копии, сделанные версиями до 2.5 (с фразой), по-прежнему читаются: при восстановлении
  приложение попросит ту фразу. Чтобы перейти на новый режим, один раз нажмите «Сохранить сейчас».
- Автоматическую копию можно выключить переключателем на том же экране.

## Что нового в 2.4

- **Вход запоминается.** При запуске приложение больше не спрашивает Google-аккаунт: если вход уже
  был, сейф открывается сразу. Отключить можно в «Настройках» → «Запомнить вход».
- Вход через Google стал тихим: Google подставляет аккаунт, которым уже входили, без выбора
  и лишних подтверждений. Первый вход на новом устройстве по-прежнему спрашивает аккаунт.
- Доступ к Google Drive тоже не переспрашивается: приложению передаётся ваш аккаунт, а полученный
  токен держится в памяти сессии (около часа) вместо нового запроса на каждый экран.
- Для защиты при запуске есть «Настройки» → «Вход по биометрии» — отпечаток или лицо вместо
  запроса аккаунта.

## Что нового в 2.3

- **Исправлена ошибка «Google Drive отклонил запрос (код 400) Invalid Value».** Причина была в
  запросе приложения, а не в настройках доступа: в Drive API v3 скрытая папка приложения

  Теперь список копий ищется правильно.

  было спутать с нехваткой прав.
- Добавлен тест-сторож, который не даст вернуть старое написание `appdata`.

## Офлайн-режим

Без настроенного ИИ работает локальная эвристика: тип секрета определяется по формату
(Luhn для карт, BIN банка, JWT с разбором издателя, префиксы токенов GitHub/GitLab/OpenAI/
Anthropic/AWS/Google/Stripe/Shopify/Mailgun/PyPI/Telegram и десятков других),
а подробное описание берётся из офлайн-базы знаний (более 60 сервисов: банки, облака,
мессенджеры, криптобиржи) со ссылками на страницы управления ключами.

## Сборка

```bash
cd Safe
./gradlew :app:assembleRelease      # подписанный APK
./gradlew :app:testDebugUnitTest    # unit-тесты
```

Требования окружения: JDK 17+, Android SDK (platform 34, build-tools 34).

Подпись релиза задаётся переменными окружения (секретов в репозитории нет):

```bash
export SAFE_STORE_FILE=../safe-release.jks   # путь к keystore
export SAFE_STORE_PASSWORD=...
export SAFE_KEY_ALIAS=safe
export SAFE_KEY_PASSWORD=...
./gradlew :app:assembleRelease
```

Без этих переменных релиз соберётся, но останется неподписанным.

Готовый APK: `../Safe-v2.7.apk`.

```
  data/ai/                      — агент, OpenAI-клиент, эвристика, база знаний,
                                  BrandCatalog (бренды), BankBin (BIN банков), BrandGrouper
  data/icons/IconRepository.kt  — поиск логотипов и генерация иконок
  ui/components/RemoteImage.kt  — загрузка удалённых изображений с кэшем
  ui/                           — экраны Compose, темы, навигация, ViewModel
```

## Безопасность

- Секреты и API-ключ агента лежат только на устройстве в зашифрованном виде.
- Ключ шифрования хранится в Android Keystore и не покидает устройство.
- Резервное копирование отключено (`allowBackup=false`).
